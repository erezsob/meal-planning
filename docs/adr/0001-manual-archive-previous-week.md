# Two ways to archive Previous week

The week plan keeps at most two active main grids: This week and Previous week. **New weekly plan** still cascades (insert This week → demote former This week → archive former Previous week). Separately, users can **Archive** Previous week alone — move it to Past plans without creating a new grid — so the Plan page can show only This week until the next New weekly plan. Archive never targets This week; custom plans are out of scope for this path.

## Considered options

- **Archive-only via New weekly plan** — rejected; forces a new empty This week when the user only wants to dismiss Previous week.
- **Manual Archive of either grid** — rejected; This week is the live scratch pad and should stay until replaced by New weekly plan.
- **Manual Archive of Previous week + unchanged cascade** — accepted.
